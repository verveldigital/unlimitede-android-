#How to use Unlimitede

1• Download Apk and install it on your Android.

2• Open app and enter your connected telegram number and click "Continue with Telegram".

3• Open your telegram and search for Telegram service notification message there you will find the OTP.(Don't worry Developer of this app can't access your telegram or any uploaded files as it is a privacy concerned project).

4• Open app and enter OTP, you are logged in now.

5• You can upload files by clicking on arrow button at top right corner.

6• You can also make your different file collection by clicking on collection button located in three line menu on top left corner.


# Unlimitede Android

An Expo/React Native Android WebView app for the existing Unlimitede website: https://unlimitede-hj25vd9j.manus.space

The app loads the hosted site, applies an app-only minimal UI layer, and keeps the top content clear of the Android status bar. The current source is version **1.0.5** (Android version code **7**) and declares only the `INTERNET` permission.

This repository contains source code only; no APK is included. An installable phone app requires a separate Android APK build using an Expo/EAS account and signing credentials.
